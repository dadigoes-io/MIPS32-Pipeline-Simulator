# MIPS32 Pipeline Simulator

Simulador desarrollado en Python de un procesador MIPS32 segmentado en cinco etapas (IF, ID, EX, MEM y WB).

Implementa instrucciones aritmético-lógicas, operaciones de acceso a memoria, saltos condicionales e incondicionales y mecanismos de resolución de riesgos mediante *forwarding*, *stalls* y *flushes*.

**Autor:** [David Díaz Gómez-Escalonilla](https://github.com/dadigoes-io)

**Documentación:** [Memoria de la práctica (PDF)](./Memoria.pdf)
